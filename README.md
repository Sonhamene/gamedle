# 🎮 Gamedle — Vibe Coded

Uma recriação do **Gamedle**, feita com JavaScript, Node.js e Prisma, misturando programação com experimentação e criatividade. O projeto foi inspirado na abordagem de desenvolvimento criativo do **Perplexity**: testar ideias, experimentar sem medo e não ficar preso em overthinking.

## 🎯 O que é?

O **Gamedle** é um jogo de adivinhação para quem acha que conhece videogames.

A cada rodada, você recebe pistas sobre um jogo e precisa descobrir qual é. Quanto mais pistas você usa, mais fácil fica — mas também menor é a sua pontuação.

É basicamente:

> **pista → chute → dúvida → "EU SABIA!" → próxima rodada** 🎮

## 🛠️ Tecnologias

* **JavaScript** — linguagem principal do projeto
* **Node.js** — ambiente utilizado para executar o projeto
* **Prisma** — ORM para gerenciamento e acesso ao banco de dados
* **SQLite** — banco de dados utilizado para armazenar os dados do jogo
